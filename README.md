# Syntax Lens

A privacy-first, context-aware linguistic lens for English notes.

## Use

Place the cursor in a prose sentence to highlight the linguistic structure around it. Hover or click an annotation for an explanation. Settings offer Minimal, Verb Study, and Sentence Structure profiles, intensity controls, and a way to clear local analysis data. The command palette can toggle the lens or cycle profiles. Analysis runs locally; note content is not sent to a server.

## Install manually

Copy `manifest.json`, `main.js`, and `styles.css` (if present) into `<vault>/.obsidian/plugins/syntax-lens/`, then enable the plugin in Obsidian.

## Source

This repository contains the installed JavaScript plugin. The original TypeScript source is not available in the vault.
